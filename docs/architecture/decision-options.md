# بازبینی گزینه‌های سبک‌تر A04 و A06

وضعیت: پیشنهاد برای تصمیم؛ نتیجهٔ benchmark یا پذیرش نهایی هنوز وجود ندارد. مسئول مقایسه W035 است.

## A04 — رابط کاربر

| معیار | Django templates + تعامل محدود | Next.js + TypeScript |
| --- | --- | --- |
| پردازش عملیاتی وب | همان runtime Python؛ Node ممکن است فقط ابزار build دارایی‌ها باشد | Python backend و Node frontend |
| صفحات عمومی و جست‌وجو | رندر HTML سمت سرور | رندر سرور و قابلیت‌های Next |
| نقشه و اسکن | ماژول JavaScript/TypeScript مستقل با endpointهای موجودی | React component با همان endpointها |
| پنل‌های پیچیده | نیازمند طراحی تعامل و componentهای مشترک | ابزارهای React؛ هزینهٔ هماهنگی API و cache |
| نگهداری و تحویل | سرویس کمتر؛ مهارت frontend همچنان لازم | سطح وابستگی و فرایند انتشار بیشتر |
| شخصی‌سازی | template و tokenهای برند | component و tokenهای برند |

پیشنهاد فعلی برای پایلوت یک سینمای شهرستان: گزینهٔ Django templates جدی‌تر و اول بررسی شود. W035 باید همان مسیر واقعی نقشهٔ صندلی، فرم مالی، اسکن روی موبایل و تم خالی را نمونه‌سازی کند. اگر تجربه یا نگهداری componentها ناکافی بود، Next با دلیل ثبت‌شده انتخاب شود؛ انتخاب بر اساس نام ابزار کافی نیست.

هر دو گزینه قواعد فروش و مالی را در backend نگه می‌دارند. داشتن API شریک بیرونی مستقل از انتخاب Next است.

## A06 — کار پس‌زمینه

| معیار | صف PostgreSQL | Celery + RabbitMQ |
| --- | --- | --- |
| دوام قصد کار | در همان تراکنش تغییر دامنه | Outbox لازم است؛ broker جای آن را نمی‌گیرد |
| اجزای اجرا | worker از image backend و DB | worker و broker و پیکربندی و پایش جدا |
| امکانات آماده | lease، retry، dead-letter و scheduler باید ساخته/آزموده شوند | بخش بزرگی آماده؛ تنظیمات و تک‌اثری همچنان لازم |
| بار | سهمی از DB فروش مصرف می‌کند | بخشی از فشار صف جدا می‌شود |
| خرابی | lease منقضی و کار تکراری باید حل شود | redelivery و confirm و duplicate باید حل شوند |

پیشنهاد فعلی v1: صف PostgreSQL در W035 ارزیابی شود؛ نه worker خام و بدون recovery. A08، Inbox/Outbox و تک‌اثری در هر دو گزینه لازم‌اند. قرارداد Job و اثر شبکه در data-model آمده است.

شرط انتخاب: زمان‌بندی استعلام‌ها، restart پس از انجام اثر و قبل از ack، رقابت workerها، عدم گم‌شدن کار، lag صف و اثر روی latency فروش در پروفایل D12 سنجیده شوند. اگر queue DB کارایی یا نگهداری کافی نداشت، broker مستقل با شاهد انتخاب شود.

## دروازهٔ تصمیم

خروجی W035 شامل نمونهٔ قابل اجرا، پروفایل و نتیجهٔ مشاهده‌شده، هزینهٔ سرویس‌ها، محدودیت‌ها و پیشنهاد نهایی است. بدون این شواهد و نظر مالک، A04 و A06 بسته نمی‌شوند. در این بازبینی فقط ارزیابی مستند انجام شده، نه اجرای این نمونه‌ها.
