# گزارش بررسی نسخهٔ ۰.۱.۰

- محیط: Python 3.14.7 / Windows.
- نتیجه: ۲۵ آزمون موفق، بدون شکست.
- آزمون رقابت آخرین صندلی: ۱۲ درخواست هم‌زمان، فقط یک رزرو موفق.
- آزمون مصرف هم‌زمان بلیط: ۸ درخواست، فقط یک پذیرش.
- آزمون ثبت هم‌زمان تسویه: دو درخواست، فقط یک مصرف مانده.
- آزمون رقابت لغو و مصرف: فقط یکی موفق.
- درخواست تکراری با کلید یکسان و تغییر محتوا، پرداخت دیرهنگام، دو پرداخت موفق، پرداخت نامشخص مستقل، لغو جزئی و ماندهٔ منفی بررسی شدند.
- اجرای نمونهٔ خرید دو صندلی تا صدور دو بلیط و ثبت سهم مرکز موفق بود.
- این بررسی آزمون بار، ممیزی امنیت، آزمون سرویس بیرونی یا تأیید آمادگی فروش عمومی نیست.
- لاگ کامل اجرای آزمون در test-results.txt قرار دارد.
