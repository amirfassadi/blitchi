# وضعیت پیاده‌سازی

## تصمیم‌های قطعی گفتگو

پکیج سینما، بازار شروع نوشهر، نصب مستقل برای هر مشتری و نام‌های فعلاً خالی. D01 از نظر پکیج و منطقه مشخص است؛ مرکز واقعی و D02/providerها هنوز بازند.

## کد فعلی: هستهٔ مرجع ۰.۲.۰

مسیر آزمایشی رزرو، سفارش، پرداخت مورد اعتماد، فروش داخلی، صدور بلیط، مصرف یا لغو و حساب مرکز وجود دارد. احراز هویت/QR/پنل/اتصال واقعی/قواعد مالی نهایی هنوز ساخته نشده‌اند.

بازبینی شش ایراد مرجع با regression انجام شده: سررسید اصلاح مالی، خطای تک‌اثری، گردکردن، خواندن صرف موجودی، مالکیت buyer و موعد پایان برنامه. replay پذیرش و رد امن schema قدیمی نیز آزموده شده‌اند. گزارش اجرا در [verification](verification.md) است.
